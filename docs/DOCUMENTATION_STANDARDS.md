# Documentation Standards

## File Organization

All markdown (`.md`) files must be stored in the `docs/` directory.

### Rules:
- ✅ All `.md` files should be placed in `docs/`
- ❌ Do not create `.md` files in the root directory
- ❌ Do not create `.md` files in component directories
- ✅ Keep all documentation centralized in `docs/`

### Directory Structure:
```
docs/
  ├── README.md                    # Main documentation index
  ├── DOCUMENTATION_INDEX.md       # Documentation catalog
  ├── DOCUMENTATION_STANDARDS.md   # This file
  └── [other documentation files]
```

### Migration Status:
✅ All existing `.md` files have been moved to `docs/` directory (as of 2025-11-29)

### Examples:
- Component documentation: `docs/COMPONENT_SHOWCASE.md`
- Setup guides: `docs/SETUP.md`, `docs/DEPLOYMENT_GUIDE.md`
- Feature documentation: `docs/FEATURE_MAP.md`
- Implementation guides: `docs/IMPLEMENTATION_COMPLETE.md`

---

**Note:** When creating new documentation, always save it in the `docs/` directory to maintain consistency and organization.
