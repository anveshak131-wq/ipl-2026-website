## 🎯 Key Information Quick Reference

### **Component Import**
```tsx
import SportsUP18Logo from '@/components/branding/SportsUP18Logo';
import SportsUP18LogoWithText from '@/components/branding/SportsUP18LogoWithText';
```

### **Basic Usage**
```tsx
<SportsUP18LogoWithText size="md" animated />
```

### **Available Sizes**
- sm (32px) - Small icons
- md (48px) - Navbar, headers
- lg (64px) - Hero section
- xl (96px) - Landing page

### **Animation Timings**
- Ball Spin: 8 seconds
- Bat Float: 3 seconds
- Ring Pulse: 2.5 seconds
- Glow Pulse: 2 seconds
- Text Gradient: 5 seconds
- Hover: 300ms

### **Color Palette**
- Gold: #fbbf24 → #f59e0b → #d97706
- Blue: #3b82f6 → #1e40af
- Pink: #ec4899 → #a855f7

### **File Locations**
- Components: `/src/components/branding/`
- Assets: `/logos/`
- Docs: `/` and `/docs/`
