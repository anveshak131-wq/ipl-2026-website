Ball Recording Debug Tests

1. Check if recordBall Function Exists

2. Check if State Updates

3. Open Network Inspector

Press F12, go to Network tab, then click a ball button on the WPL page

You should see API calls to /api/live-score with POST requests

4. Check Browser Console

Press F12, go to Console tab

Look for logs starting with "[recordBall]" when you click a button

If you see nothing, the button click is not reaching recordBall

5. Manual Test Steps

  1. Open http://localhost:3000/wpl-admin-2026/live-score in Chrome
  2. Press F12 to open Developer Tools
  3. Go to Console tab
  4. Click "Dot (0)" button
  5. WATCH the console for messages
  6. If you see "[recordBall] Updating: ...", the fix works
  7. If nothing appears, there's still an issue
